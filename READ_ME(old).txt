💾 Installation :

	1. Décompressez le fichier MoyenneUE.zip (clic droit sur le fichier, puis choisissez "Extraire tout…")
	2. Ouvrez le dossier MoyenneUE.
	3. Double-cliquez sur MoyenneUE.exe pour lancer le programme.

⚠️ Ne supprimez/déplacez pas les autres fichiers de ce dossier, sans eux le code ne fonctionne pas. ⚠️


📁 Créer un raccourci sur Windows :

	1. Faites un clic droit sur MoyenneUE.exe.
		1.2 Cliquez sur "Afficher plus d’options" (Seulement pour Windows 11)
	2. Sélectionnez "Envoyer vers".
	3. Cliquez sur "Bureau (créer un raccourci)".


🔌 Exécution :

Sur Windows, lorsque vous allez vouloir lancer MoyenneUE.exe pour la première fois, 
une fenêtre avec marqué "Windows a protégé votre ordinateur" va apparaître. 
L'apparition de ce message est normale, et vise à protéger votre ordinateur de tout programme pouvant être malveillant.
Pour exécuter ce programme malgré tout :

	1. Cliquez sur "Informations complémentaires"
	2. Cliquez sur "Exécuter quand même"
